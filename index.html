O que é um If ?

Imagine que o Robogério precisa tomar uma decisão. O if serve justamente para isso!

Ver Explicação Técnica

O if é uma estrutura condicional usada para tomar decisões no código. Ele verifica se uma condição é verdadeira ( true ) e, caso seja, executa o bloco de código que está dentro das chaves { } .

Exemplo: 

let moedas = 7;

if (moedas < 5) {
    console.log("Faltam moedas");
}


if → significa "se". É o comando que inicia uma verificação.

( ) → dentro dos parênteses fica a condição que será analisada pelo programa.

< → significa "menor que". Ele compara dois valores para verificar se a condição é verdadeira ou falsa.

{ } → indicam o bloco de código que será executado caso a condição seja verdadeira.

O que é um Else If ?

O else if é usado quando precisamos verificar uma nova condição caso a condição anterior do if seja falsa. Assim, podemos testar diferentes possibilidades e executar uma ação diferente para cada condição.

Ver Explicação Técnica

O else if é uma estrutura condicional usada para verificar uma nova condição quando a condição do if anterior é falsa. Se essa nova condição for verdadeira ( true ), o bloco de código dentro das chaves { } será executado.

Exemplo: 

let moedas = 7;

if (moedas < 5) {
    console.log("Poucas moedas");
}
else if (moedas < 10) {
    console.log("Quantidade média");
}


else if → significa "senão, se". Ele cria uma nova verificação caso o if anterior seja falso.

( ) → dentro dos parênteses fica a nova condição que será analisada pelo programa.

{ } → indicam o bloco de código que será executado caso a condição do else if seja verdadeira.

O que é um Else ?

O else é usado para definir o que acontece quando a condição do if é falsa. Ou seja, se nenhuma das verificações anteriores for verdadeira, o código dentro do else será executado.

Ver Explicação Técnica

O else é uma estrutura condicional usada para executar uma ação quando todas as condições anteriores forem falsas. Ou seja, se o if e o else if não forem verdadeiros, o bloco de código dentro das chaves { } do else será executado.

Exemplo: 

let moedas = 7;

if (moedas < 5) {
    console.log("Poucas moedas");
}
else if (moedas < 10) {
    console.log("Quantidade média");
}
else {
    console.log("Muitas moedas");
}


else → significa "senão". Ele é executado quando nenhuma das condições anteriores forem verdadeiras.

{ } → indicam o bloco de código que será executado quando todas as condições anteriores forem falsas.

else → não possui uma condição dentro dos parênteses ( ) , pois ele representa o último caminho possível da decisão.
